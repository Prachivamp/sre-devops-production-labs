# SRE/DevOps Production Labs

This repository contains my hands-on SRE and DevOps learning labs.

The goal is to build practical technical knowledge by working with real-world concepts, common production problems, troubleshooting scenarios, and automation.

## Learning Approach

Each lab follows this process:

1. Learn the concept
2. Perform the hands-on exercise
3. Create or reproduce a common problem
4. Troubleshoot the problem
5. Fix and verify the issue
6. Document what I learned
7. Commit the changes to Git
8. Push the work to GitHub

## Philosophy

The focus of these labs is not memorizing commands.

The goal is to understand:

**What is happening → How to investigate → Why it is happening → How to fix it → How to prevent it**
